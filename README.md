# FOCO English A1-A2

Aplicação PWA offline criada a partir dos quatro materiais FOCO English.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie **todos os ficheiros desta pasta para a raiz do repositório**.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione **main**, pasta **/(root)** e clique em **Save**.
6. Abra o endereço disponibilizado pelo GitHub Pages.

## Funcionalidades
- 4 módulos e todas as lições extraídas dos PDFs
- níveis A1 e A2, pesquisa e progresso
- cronómetro por lição
- atividades concluídas por secção
- notas e respostas guardadas automaticamente
- exportação do progresso
- instalação como PWA e funcionamento offline

## Nota
Os dados são guardados no navegador com localStorage. Para sincronização entre vários dispositivos, será necessária uma base de dados e autenticação numa futura versão.
